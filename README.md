# App Privacy Policies

Public privacy-policy pages for applications developed under `afedida`.

## HydroFlow

- **Public policy:** https://afedida.github.io/app-privacy-policies/hydroflow/
- **Languages:** English and Hebrew
- **Source policy:** the private HydroFlow project's `store/privacy_policy.md` (October 2026)

## Publish with GitHub Pages

Open **Settings → Pages**, select **Deploy from a branch**, then select **main** and **/(root)**, and click **Save**. Once deployed, verify the public link above without logging in before entering it in Google Play Console under **App content → Privacy policy**.

These pages are static HTML, require no account, and use no analytics, cookies, tracking scripts, or external resources. For privacy questions, see the developer contact on the Play listing or open a GitHub issue without sharing sensitive information.

New applications can be added at `<app-name>/index.html`.
